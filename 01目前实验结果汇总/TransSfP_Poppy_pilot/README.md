# TransSfP × Poppy (MoGe-2) 7-object × 3-frame pilot

Zero-shot Poppy + MoGe-2 on the TransSfP held-out real test split, compared with
the TransSfP reproduction (epoch 20 checkpoint, 17.22° overall).

## Setup

- 7 test objects × 3 frames = 21 frames.
- Frames chosen at the 25/50/75 percentiles of each sequence (1-based), not by error.
- Polarization images resized to 512×512 (LANCZOS); mask NEAREST; GT normal BILINEAR.
- MoGe-2 base: `num_opt=1`, all learning rates 0 (backbone prediction only).
- Poppy Full: official settings, `num_opt=100`, `image_lr=1e-5`, `fs_lr=1e-2`,
  `normal_lr=1e-3`.
- TransSfP reference: per-object mean angular error from `results/transsfp_eval/metrics_summary.csv`.
- Cost: ~119 s/frame on one GPU; full 299-frame run would be ~9.8 h.

## Visualizations

Generated by `baselines/tools/visualize_transsfp_poppy_pilot.py`:

- `figs/overview.png` — 7 rows (one middle frame per object) × 6 columns:
  input, GT normal, MoGe-2 base normal, Poppy normal, base error, Poppy error.
- `figs/per_object/<object>.png` — all 3 pilot frames per object, same 6 columns.
- `figs/object_bars.png` — object-level base / Poppy / TransSfP bars, with the
  5-object mean called out.
- `figs/per_frame_scatter.png` — per-frame base error vs Poppy error; points
  below the diagonal improved.
- `per_frame_summary.csv` — per-frame base/Poppy error and delta.

Normal maps are rendered as `(n+1)/2` with masked-out pixels white. Error maps
use a shared 0–90° `inferno` scale. Poppy's own per-frame normal maps and
`Ls`/`Ld` maps remain in `base/vis/` and `full_official/vis/`.

Visually, Poppy's improvement on cups/cats/bird comes from correcting the
surface shading/orientation across the object body, and the error maps shrink
roughly uniformly. On the hemispheres the error is a large ring around the
center in both base and Poppy, and Poppy's ring grows — consistent with a global
orientation/curvature failure of the backbone, not local noise.

## Interpretation

1. **Poppy improves the backbone on 5 of 7 objects.** Bird, both cats, and both
   cups all improve; the 5-object mean drops from 26.81° to 20.98° (−5.83°).
2. **On the two tiny cups Poppy slightly beats the trained TransSfP model**
   (13.86 vs 14.93; 15.91 vs 17.07). Cat-front nearly ties (+1.14°).
   This is zero-shot refinement of a frozen RGB normal estimator, so the
   comparison is favorable to TransSfP, which was trained on this dataset.
3. **The hemispheres fail catastrophically and dominate the 7-object average.**
   MoGe-2 base is already ~47–52° off; Poppy pushes it to ~69–71°. This is the
   same failure seen in the single-frame diagnostics: MoGe-2 predicts nearly flat
   normals (z median 0.98 vs GT 0.70), and Poppy's additive normal offset plus
   image optimization cannot recover a ~50° global orientation error, converging
   to a wrong local minimum. No axis flip or exposure normalization fixes it.
4. **Therefore the headline "All 7 objects" number is misleading.** Report the
   per-object table and the 5-object mean; the hemisphere cases are a backbone
   failure mode, not a Poppy optimization result.

## Caveats

- Only 3 frames per object; per-frame variation can be several degrees
  (e.g. bird-back frame 027 is 39.55° vs ~28–29° on the other two).
- 512×512 downsampling; native-resolution polarization was checked on one
  hemisphere frame and did not change the base error (54.04° vs 54.18°).
- Input polarization images are grayscale, while Poppy's default MoGe-2 pipeline
  expects its own RGB capture format; this is a cross-dataset adaptation.
- TransSfP was trained on these objects; Poppy is zero-shot.

## Recommendation

The pilot is sufficient to establish the qualitative conclusion: Poppy helps
when the backbone is already in the right basin (cups, cats, bird) and hurts
when it is not (hemispheres). A full 299-frame run (~9.8 h) would tighten the
per-object means but would not change the hemisphere failure. If full numbers
are needed for a report, run the full set only on the 5 non-hemisphere objects
(260 frames, ~8.6 h) and keep the hemispheres as a documented limitation.
